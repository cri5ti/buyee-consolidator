

- build a web app
- vite, typescript, tailwind, react


# inport
- upload a buyee export, see buyee.html file


- extracts all items, especially:
  - package number
  - original value (yen)
  - weight (g)
  - dimensions (cm) (e.g. 20x32x9)
  - free storage days

  - calculate the value in gbp (use 0.004708 exchange rate ; include in config)
  - calculate volume

- present a grid of all items
- allow sorting by clicking on the header


# consolidation
- clicking a row selects it (highlight / shade)
- using up/down arrows selects prev / next

- pressing buttons 1/2/3/.. etc assigns the item to consolidation box 1/2 ...; 0 unassigns it from any consolidation


- on the bottom of screen (fixed) show the boxes used:
    - count items
    - sum of price
    - sum of weight
    - sum of volume
